# Application 01: Word Counter

A clean, beginner-friendly web application to calculate text statistics in real time.

## Features
- **Real-time Live Statistics:** Words, characters (with spaces), characters (without spaces), sentences, and paragraphs update immediately as you type or paste.
- **Reading Time Estimation:** Estimates reading duration based on an average reading speed of 200 words per minute.
- **Copy and Clear:** Quick buttons to clear input or copy text to clipboard.
- **Sample Text:** Includes a built-in sample text loader for quick demonstration.

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla ES6)

## How to Run
Simply double-click `RUN.bat` or open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave). No installation required!
